# 聞き取りテストの受付（Google Apps Script）の設置

テストページ（https://labphonlab.github.io/english-phonetics-listening/lecture03/test.html）は、
最後の問題に答えた時点で解答をここへ送る。結果はスプレッドシートに1受験1行（「結果」）と1問1行（「解答」）で残る。

## 一度だけの設置（約5分）

1. **個人の Google アカウント（gmail）**で新しいスプレッドシートを作る（名前は例：英語音声学 聞き取りテスト結果）。
   大学アカウントだとウェブアプリの公開範囲を「全員」にできず、GitHub Pages からの送信が通らない（voice-submit と同じ理由）。
2. 拡張機能 → Apps Script を開き、`Code.gs` の中身をこのフォルダの `Code.gs` で置き換えて保存。
3. 関数 `setup` を選んで実行（初回は権限の確認が出る → 許可）。シート「結果」「解答」「設定」ができる。
4. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 表示された URL（`https://script.google.com/macros/s/…/exec`）を `web/config.js` の `apiUrl` に入れて push する
   （Claude に URL を渡せば反映する）。

## 運用

- 受付を止める：シート「設定」の B1 を `しない` にする（ページは「いまは受け付けていません」と出して始められない）。再開は `する`。
- 同じ学生が何度受けてもよい。「結果」の「回目」が 1, 2, … と増える。成績に使う回は運用で決める。
- 学籍番号は全角を半角にし、大文字にそろえて記録する。氏名は入力どおり。
- 送信に失敗した結果は学生の端末に残り、「もう一度送信する」か、次にページを開いたときに自動で送り直す。同じ受験が2回届いても1行だけ残る。
- Code.gs を直したら、デプロイの管理 → 編集 → バージョン「新バージョン」で更新する（URL は変わらない）。
