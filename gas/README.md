# 聞き取りテストの受付（Google Apps Script）の設置

テストページ（https://labphonlab.github.io/english-phonetics-listening/lecture03/test.html）は、
最後の問題に答えた時点で解答をここへ送る。結果はスプレッドシートに1受験1行（「結果」）と1問1行（「解答」）で残る。

## 一度だけの設置（約5分）

1. **個人の Google アカウント（gmail）**で新しいスプレッドシートを作る（名前は例：英語音声学 聞き取りテスト結果）。
   大学アカウントだとウェブアプリの公開範囲を「全員」にできず、GitHub Pages からの送信が通らない（voice-submit と同じ理由）。
2. 拡張機能 → Apps Script を開き、`Code.gs` の中身をこのフォルダの `Code.gs` で置き換えて保存。
3. 関数 `setup` を選んで実行（初回は権限の確認が出る → 許可）。シート「結果」「解答」「設定」ができる。
4. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 表示された URL（`https://script.google.com/macros/s/…/exec`）を `web/config.js` の `apiUrl` に入れて push する
   （Claude に URL を渡せば反映する）。

## 運用

- 受付を止める：シート「設定」の B1 を `しない` にする（ページは「いまは受け付けていません」と出して始められない）。再開は `する`。
- 同じ学生が何度受けてもよい。「結果」の「回目」が 1, 2, … と増える。成績に使う回は運用で決める。
- 学籍番号は全角を半角にし、大文字にそろえて記録する。氏名は入力どおり。
- 送信に失敗した結果は学生の端末に残り、「もう一度送信する」か、次にページを開いたときに自動で送り直す。同じ受験が2回届いても1行だけ残る。
- Code.gs を直したら、デプロイの管理 → 編集 → バージョン「新バージョン」で更新する（URL は変わらない）。

## 発音テスト（録音の提出）を使えるようにする（2026-11 追加・一度だけ）

聞き取りテストと同じスプレッドシート・同じウェブアプリ URL のまま、録音の受付を足す。`config.js` は変えない。

1. このスプレッドシートの 拡張機能 → Apps Script を開き、`Code.gs` の中身を、このフォルダの新しい `Code.gs` で**全部**置き換えて保存。
2. 関数 `setup` を選んで実行。**ドライブの権限**の確認が新しく出るので許可する（「確認されていません」→「詳細」→「移動」）。
   - シート「録音提出」「録音」、設定の3行目「録音の受付」、ドライブのフォルダ「英語音声学_録音提出」ができる。今までのシート・結果はそのまま。
3. デプロイ → デプロイを管理 → 既存のデプロイを編集（鉛筆）→ バージョン「新バージョン」→ デプロイ。**URL は変わらない**。
4. スプレッドシートを開き直すと、メニューに「英語音声学」が出る。

手順 3 を忘れると、発音テストのページは「受付の準備ができていません」と出して始められない（聞き取りテストは今までどおり動く）。

### 運用

- 学生用ページ（第3〜6回）。どちらも同じ受付・同じシートに入り、「テスト」列で分かれる。
  - 発音の課題 `lectureNN/speak.html`（図なし）・`lectureNN/analyze.html`（音声分析つき）：testId `lNN-task`。お手本のあとに言って何回でも録り直し、納得した録音を項目ごとに「決定」→ 全部決めたら「提出する」。
  - 発音テスト `lectureNN/record.html`：testId `lNN-speak`。お手本なし。録音を止めると（話し終わると自動でも止まる）その場で送信して次の問題へ。聞き直し・録り直しはしない（声が録れていない・音割れのときだけ、その問題を2回まで録り直せる）。
- 「録音回数」列：課題は決定までに録った回数、テストは技術的な録り直しを含めた回数。
- 録音の受付を止める：シート「設定」の B3 を `しない`（聞き取りテストの B1 とは別）。
- 録音は WAV（16bit・モノラル・端末のサンプリング周波数。加工なし）で `英語音声学_録音提出/<テスト>_<名前>/<学籍番号>_<氏名>/` に入る。ファイル名は「テスト_学籍番号_問_提示文_開始日時.wav」。
- シート「録音」：1録音1行（提示文・領域・見る点・秒数・録音回数・ファイル・**評価**・メモ）。「録音提出」：1提出1行（回目・状態・得点・満点・採点済み）。
  同じ学生が出し直すと、前の提出は状態が「以前」になり、採点の対象は「最新」だけになる。
- **採点**：メニュー「英語音声学」→「録音を採点する」。テストを選び「読み込む」。録音が自動で流れるので、0・1・2 のキーかボタンで評価すると次へ進む（R＝もう一度、←→＝移動、メモは Enter で保存）。
  尺度は教科書 付録G.6：0＝まだ難しい、1＝意識すればできる、2＝課題内で安定。
  「問題ごと」（全員の問1 → 全員の問2 …）で聞くと基準がぶれにくい。「氏名を隠す」で名前を見ずに採点できる。
- 学生の声と氏名は個人情報。スプレッドシートとフォルダは共有しない。学期が終わったら大学の保存先へ移し、個人のドライブから消す。
- 受付 URL を知っていれば誰でも送れる（テストIDの形・学籍番号の形・WAV であること・サイズ 12 MB までを確かめるだけ）。
